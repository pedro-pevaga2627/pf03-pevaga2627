# PF03. Actividad 1 TDD + Node + CI

Este repositorio contiene la **Actividad 1 (PF03)** del módulo de Proyecto Intermodular.

El objetivo principal es implementar un flujo de trabajo colaborativo mediante GitFlow, aplicando la metodología **TDD** y automatizando la ejecución de las pruebas mediante **CI** con **GitHub Actions**.

## Funcionalidades implementadas

1. **Sucesión de Fibonacci**
2. **Validación de PIN**

## Tecnologías utilizadas

- Node.js.
- Vitest.
- Chalk.
- CI.

## Cómo ejecutar el proyecto

1. Instalar las dependencias:

   ```
   npm install
   ```

2. Ejecutar las pruebas una sola vez:

   ```
   npm run test
   ```

3. Ejecutar las pruebas en modo escucha:

   ```
   npm run test:watch
   ```
