# PF03. Actividad 1: TDD + Node + CI

Este repositorio contiene la **Actividad 1 (PF03)** del módulo de Proyecto Intermodular.

El objetivo principal es implementar un flujo de trabajo colaborativo mediante GitFlow, aplicar la metodología **TDD (Test Driven Development)** y automatizar la ejecución de las pruebas mediante **Integración Continua (CI)** con GitHub Actions.

## Funcionalidades implementadas

1. **Sucesión de Fibonacci.**
2. **Validación de PIN.**

## Tecnologías utilizadas

- Node.js.
- Vitest.
- Chalk.
- GitHub Actions (CI).

## Cómo ejecutar el proyecto

1. Instalar las dependencias del proyecto:

   ```bash
   npm ci
   ```

2. Ejecutar las pruebas una sola vez:

   ```bash
   npm run test
   ```

3. Ejecutar las pruebas en modo escucha:

   ```bash
   npm run test:watch
   ```
